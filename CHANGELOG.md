# Changelog

## 1.0.0 - 2026-11-05

- Ship an original Rust Minesweeper engine with safe-first generation, flood reveal, flags, chording, and exact win/loss detection.
- Add responsive rendering, cursor-centered viewports, keyboard navigation, and mouse control.
- Add beginner, intermediate, expert, custom, and seeded board modes.
- Freeze completed boards under explicit win/loss overlays.
- Persist top-ten completion times per exact field configuration.
- Isolate modal input and retain rankings per field so shorter presets cannot evict expert records.
- Add strict local quality, dual-remote release, and Cargo installation targets.
